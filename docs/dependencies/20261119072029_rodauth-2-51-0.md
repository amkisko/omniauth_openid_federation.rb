## Dependency

- rodauth (was 2.44.0 / 2.45.0, now 2.51.0)
- Development gemspec floor now `~> 2.0, >= 2.50.0`
- Integration-test only via rodauth-omniauth. Not a published runtime dependency.

## Symptom

bundler-audit matched rodauth 2.44.0 against several advisories (WebAuthn account takeover, TOTP reuse, OTP drift replay, return-to redirect, CSRF content-type, jwt_refresh).

## Evidence

- bundler-audit solutions ranged through `>= 2.46.0` up to `>= 2.50.0` depending on the advisory.
- Registry latest at fix time: 2.51.0.

## Suggested fix

Upgrade lockfiles to rodauth 2.51.0 and raise the development gemspec floor to `>= 2.50.0`.
